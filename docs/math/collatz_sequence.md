# Collatz Sequence (3n+1 Problem)

## 1. Overview

The **Collatz sequence** (also called the 3n+1 problem, hailstone sequence) is generated by repeatedly applying a simple rule: if even, divide by 2; if odd, multiply by 3 and add 1. The **Collatz conjecture** states that this sequence eventually reaches 1 for any positive starting number.

**File**: `src/math/collatz_sequence.rs`

## 2. Mathematical Foundation

### 2.1 Definition

For a positive integer $n$:

$$f(n) = \begin{cases} n/2 & \text{if } n \text{ is even} \\ 3n + 1 & \text{if } n \text{ is odd} \end{cases}$$

### 2.2 The Collatz Conjecture

**Conjecture**: For every positive integer $n$, the sequence eventually reaches 1.

This is one of the most famous unsolved problems in mathematics!

### 2.3 Example Sequences

**n = 10**: 10 → 5 → 16 → 8 → 4 → 2 → 1 (6 steps)

**n = 27**: Takes 111 steps, reaching a maximum of 9232!

| Starting n | Steps to 1 | Maximum Value |
|------------|------------|---------------|
| 1 | 0 | 1 |
| 2 | 1 | 2 |
| 7 | 16 | 52 |
| 27 | 111 | 9232 |
| 97 | 118 | 9232 |
| 871 | 178 | 190996 |

## 3. Implementation

```rust
pub fn sequence(mut n: usize) -> Option<Vec<usize>> {
    if n == 0 {
        return None;
    }
    let mut list: Vec<usize> = vec![];
    while n != 1 {
        list.push(n);
        if n.is_multiple_of(2) {
            n /= 2;
        } else {
            n = 3 * n + 1;
        }
    }
    list.push(n);
    Some(list)
}
```

### 3.1 Usage Example

```rust
let seq = sequence(10).unwrap();
// Result: [10, 5, 16, 8, 4, 2, 1]

let seq = sequence(15).unwrap();
// Result: [15, 46, 23, 70, 35, 106, 53, 160, 80, 40, 20, 10, 5, 16, 8, 4, 2, 1]

let invalid = sequence(0);
// Result: None
```

## 4. Complexity

- **Time**: O(?) - Unknown! No proven upper bound
- **Space**: O(k) where k = sequence length

### 4.1 Why Unknown?

The Collatz conjecture remains unproven. We don't know:
- If all sequences terminate
- Upper bound on sequence length
- Upper bound on maximum value reached

## 8. Variants

### 8.1 Shortened Form

The sequence 4 → 2 → 1 always ends iterations, so odd numbers can skip:
$$f(n) = \frac{3n + 1}{2}$$ when n is odd (combines two steps)

### 8.2 Syracuse Sequence

Only track odd numbers in the sequence.

## 9. Why It's Unsolved

- Erdős: "Mathematics is not yet ready for such problems"
- No algebraic structure to exploit
- Behavior appears pseudorandom
- Connected to complex dynamics and fractals
